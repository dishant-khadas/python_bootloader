# Python Bootloader Error Codes

This document provides a comprehensive list of all error codes generated by the Python Bootloader Application during its operation lifecycle. The errors are categorized into four distinct phases to help support engineers and developers quickly identify the failure context.

---

## 1. Login & Authentication Phase (`L-XX`)
*Errors occurring during the initial service engineer login process.*

| Error Code | Error Name                  | Description |
| :--------- | :-------------------------- | :---------- |
| **L-10**   | Login Network Error         | Failed to connect to the remote server. |
| **L-11**   | Invalid Credentials         | Incorrect phone number or password. |
| **L-12**   | Login API Timeout           | Login request timed out. |
| **L-13**   | Missing Authentication Data | Missing JWT token or employee data in API response. |

---

## 2. Handshake & DU Detection Phase (`H-XX`)
*Errors occurring while the system communicates via serial port to detect the DU (Dispenser Unit) and read its initial 512-byte payload.*

| Error Code | Error Name                  | Description |
| :--------- | :-------------------------- | :---------- |
| **H-14**   | Serial Port Open Error      | Unable to open serial port. |
| **H-31**   | Serial Read Timeout         | No data received during handshake. |
| **H-39**   | No DU Assigned              | No DU assigned to the Service Engineer. |
| **H-40**   | DU_Update API Error         | Failed to fetch firmware update list. |
| **H-42**   | Invalid Frame Formatting    | Missing or invalid SOP/EOP markers. |
| **H-43**   | CRC Validation Failed       | CRC mismatch indicating data corruption. |
| **H-52**   | Frame Decryption Failed     | Failed to decrypt handshake payload. |
| **H-58**   | Invalid Serial Number       | DU or Display Number format is invalid. |
| **H-59**   | Invalid Hardware Type       | Unrecognized hardware identifier. |

---

## 3. Firmware Download & Prep Phase (`D-XX`)
*Errors occurring while downloading the selected firmware update, validating its integrity, and decrypting the payload before flashing.*

| Error Code | Error Name                  | Description |
| :--------- | :-------------------------- | :---------- |
| **D-20**   | No Firmware Available       | No firmware updates found for this device. |
| **D-21**   | Download API Failed         | Failed to download firmware file. |
| **D-22**   | Missing Headers             | Missing Hash or KMS headers in API response. |
| **D-23**   | Encrypted Hash Mismatch     | Downloaded file hash does not match server hash. |
| **D-24**   | Original Hash Mismatch      | Decrypted file hash does not match server hash. |
| **D-25**   | KMS Decryption Error        | AWS KMS failed to decrypt data key. |
| **D-26**   | AES File Decryption Error   | Failed to decrypt firmware file payload. |
| **D-28**   | Serial Write Error          | Failed to send hash packet over serial. |
| **D-29**   | Hash Packet Timeout         | No response received after sending hash packet. |

---

## 4. Firmware Programming Phase (`P-XX`)
*Errors occurring while the `btl_host.py` utility physically flashes the binary onto the PIC32 hardware.*

| Error Code | Error Name                  | Description |
| :--------- | :-------------------------- | :---------- |
| **P-15**   | Firmware Update Failed      | Flashing process exited with an error. |
